# Repository guidance

- Before changing behavior, read the relevant sections of `README.md`.
- For development and validation, consult `package.json` scripts and
  the Development and TDD section of `README.md`.
- Before exploring code, read `docs/agents/domain.md`.
- For issue tracker operations, read `docs/agents/issue-tracker.md`.
- For triage, also read `docs/agents/triage-labels.md`.

Use Conventional Commits for commit messages:
`type(scope): description` (scope optional).
