this independent project. It does not claim ownership of upstream material
or identify any upstream author as a lockgrok maintainer.

The root ISC license does not relicense the third-party skills or fonts.
Installed dependencies retain their respective licenses. Skills are development
sources and are excluded from the npm tarball.

## Publication status

The package metadata permits npm publication. Local packing and installation
remain supported.

On 2026-10-23, the maintainer considered the no-ai-slop publication concern
resolved based on Louis Rossmann's invitation to add the rules to projects.
The [permission record](third-party-notices/no-ai-slop.txt) preserves the supplied
quotation, source URL, verification limits, and maintainer decision. No SPDX
license is assigned to the upstream material.
